📘 3 Định Dạng JSON Input Được Hỗ Trợ
1. File chuẩn autosar_modules.json: Chứa toàn bộ layers, modules[], flows[] và basePath.
2. JSON cập nhật nhanh dạng Key-Value: Chỉ cần liệt kê ModuleId: "ten_file.html" (module đã có sẽ tự gắn link, module chưa có sẽ tự thêm mới).
{
  "NvM": "Simulation/03_Services/AUTOSAR_NvM.html",
  "CanIf": "Simulation/04_ECU_Abstraction/AUTOSAR_CanIf.html",
  "BswM": "Simulation/03_Services/AUTOSAR_BswM.html"
}
3. JSON Patch có thêm module mới:
{
  "links": { "NvM": "Simulation/03_Services/AUTOSAR_NvM.html" },
  "addModules": [
    { "id": "E2E", "name": "End-to-End Protection", "layer": "services", "stack": "comm", "htmlPath": "Simulation/03_Services/AUTOSAR_E2E.html" }
  ]
}
